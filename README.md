# دكتور الميكاترونكس الذكي | Smart Mechatronics Doctor

منصة تعليمية هندسية ذكية متكاملة ومتطورة لطلاب ومهندسي الميكاترونكس، تجمع بين الأساتذة الافتراضيين بشخصيات أصلية، والسبورة التفاعلية، ومختبرات المحاكاة الحية، واستوديو توليد الدروس المرئية، والحاسبات الهندسية، وحلول المسائل المدعومة بالذكاء الاصطناعي الأكاديمي.

---

## 🚀 الميزات والخدمات المكتملة في المنصة (Completed Features)

1. **الهوية والتصميم الهندسي العصري:**
   - واجهة عربية افتراضيًا تدعم RTL بالكامل مع زر تبديل فوري للإنجليزية (LTR).
   - ألوان كحلي وأزرق تقني، مع خلفيات هندسية شبكية (Blueprint) وتصميم متجاوب على الهواتف والأجهزة اللوحية والكمبيوتر.
   - جميع الخدمات حقيقية وقابلة للتفاعل ولا توجد أزرار وهمية.

2. **الأستاذ الافتراضي والسبورة التفاعلية (Virtual Professors & Whiteboard):**
   - 7 أساتذة افتراضيين بشخصيات وتخصصات متنوعة:
     - **د. عمر فاراداي**: أستاذ الدوائر الكهربائية والإلكترونيات (مستوحى من الرسم التفاعلي لدوائر RL/RC/RLC AC Circuits).
     - **د. طارق خوارزمي**: أستاذ الرياضيات الهندسية وتحويلات لابلور.
     - **د. كمال نيوتن**: أستاذ الفيزياء والديناميكا.
     - **م. ريان كودر**: مهندس الأنظمة المدمجة وبرمجة الأردوينو.
     - **د. ماجد ديناميكا**: أستاذ التصميم الميكانيكي والتروس.
     - **د. سارة سايبر**: أستاذة الروبوتات والذكاء الاصطناعي والحركيات.
     - **م. بسام دقة**: مهندس القياسات والحساسات والأتمتة الصناعية.
   - سبورة تفاعلية متحركة تدعم مؤثر القلم، وتوليد القوانين، ومسارح شروحات متتابعة.
   - نطق صوتي عربي كامل (Web Speech API) مع التحكم في سرعة العرض (0.75x, 1.0x, 1.25x, 1.5x) وكتم الصوت.

3. **استوديو إنشاء الدروس المرئية (Visual Lesson Studio):**
   - توليد سيناريو درس مرئي كامل لأي موضوع مع:
     - مقدمة وأهداف تعليمية.
     - مشاهد سبورة متدرجة وشرح صوتي لكل مشهد.
     - مثال تطبيقي محلول خطوة بخطوة مع الناتج النهائي.
     - أسئلة تفاعلية (Mini-Quiz) أثناء الدرس مع التحقق الفوري.
     - ملخص الدرس.
   - وضعان للتشغيل:
     1. **الدرس التفاعلي الحي (Interactive Web Player)**: يعمل مباشرة في المتصفح بكل كفاءة وبدون تكلفة خارجية.
     2. **تصدير فيديو MP4**: متاح مع لوحة إعداد لمزودي الفيديو الخارجيين مع توضيح شفاف للمستخدم حول الحاجة لمفتاح API خاص.

4. **مختبرات المحاكاة التفاعلية (Simulation Labs):**
   - **مختبر دوائر التيار المتردد (RL - RC - RLC AC Lab)**: راسم إشارة تفاعلي للجهد $V(t)$ والتيار $I(t)$، زاوية الطور $\phi$، حساب المعاوقة $Z$، ومؤشر رنين كهربائي تفاعلي مع زر القفز للرنين $f_0$.
   - **مختبر قانون أوم وقوانين كيرشوف**: محاكاة حركة الإلكترونات في الأسلاك، التبديد الحراري للمقاومات، وتفرع التيارات عند العقد $I_{total} = I_1 + I_2$.
   - **مختبر المنطق الرقمي (Digital Logic)**: بوابات AND, OR, NOT, NAND, NOR, XOR, XNOR مع مفاتيح تفاعلية ومصباح LED وجدول حقيقة تفاعلي.
   - **مختبر الذراع الروبوتية (Robotic Arm)**: حسابات الحركيات المباشرة والعكسية (Forward & Inverse Kinematics) مع مساحة العمل وإمكانية النقر في الفضاء لتحريك الذراع.
   - **مختبر التحكم التلقائي (PID Control)**: محاكاة استجابة النظام من الدرجة الثانية، ضبط $K_p, K_i, K_d$، ورسم بياني لنسبة التجاوز (Overshoot) وزمن الصعود.
   - **مختبر الأردوينو والمتحكمات (Arduino MCU)**: محاكاة أطراف Arduino UNO، محرك السيرفو، حساس المسافة بالموجات فوق الصوتية، ومحرر كود C++.

5. **الحاسبات الهندسية (Engineering Calculators):**
   - حاسبة قانون أوم والقدرة الكهربائية ($V, I, R, P$).
   - حاسبة المقاومات على التوالي والتوازي مع تنبيهات القيود الفيزيائية.
   - حاسبة العزم والقدرة وسرعة الدوران ($P = \tau \cdot \omega$).
   - حاسبة نسب التروس ونقل العزم والسرعة ($N_{driven} / N_{driver}$).
   - حاسبة دوائر RC وثابت الوقت وتردد القطع ($\tau = RC$).
   - حاسبة محركات الخطوة والسيرفو والنبضات بالثانية.
   - محول الوحدات الهندسية (العزم، الضغط، القدرة، الزوايا).

6. **خدمات الذكاء الاصطناعي الهندسية (AI Toolkit):**
   - اشرح لي (مبسط، جامعي، متقدم).
   - حل المسألة (إدخال نص أو رفع صورة المخطط مع مراجعة الوحدات).
   - لماذا هذا القانون؟ (الأصل الفيزيائي والفرضيات وحدود الاستخدام).
   - اشتقاق المعادلات خطوة بخطوة.
   - اكتشف خطئي (فحص حل الطالب وتصحيحه بروح تربوية).
   - قارن بين المفاهيم (جداول مقارنة فنية بين المحركات أو الحساسات).
   - مساعد المختبر (خطوات التجارب، الأدوات، واحتياطات السلامة).
   - قاموس المصطلحات الهندسية (أكثر من 60 مصطلح بالإنجليزية والعربية والقوانين).
   - التعرف الصوتي على الأسئلة عبر الميكروفون.

7. **المكتبة الهندسية (Library):**
   - رفع وإدارة مذكرات وملفات PDF ومستندات وصور محليًا.
   - تلخيص ذكي فوري للمستندات واستخراج النقاط الأساسية.
   - مراجع تجريبية واضحة وموسومة بدقة.

8. **الاختبارات والتقييم الأكاديمي (Quizzes):**
   - اختبارات شاملة مع مسائل حسابية واختيار من متعدد.
   - تصحيح آلي فوري مع شرح سبب صحة أو خطأ كل خيار.
   - احتفال تفاعلي (Confetti) عند التفوق.
   - إمكانية طباعة وتصدير تقرير النتائج.

9. **لوحة الطالب (Student Dashboard):**
   - ملف الطالب، التخصص، المستوى الدراسي.
   - سجل الاختبارات، الملاحظات الهندسية المحفوظة، وتفضيلات الصوت.

10. **لوحة الإدارة والأمان (Admin Portal):**
    - محمية بكلمة مرور مشفرة (`admin2025`).
    - تفعيل وتعطيل الخدمات، فحص اتصال الذكاء الاصطناعي، وتصدير نسخة احتياطية كاملة (Export JSON).

## 🛠️ البنية التقنية (Tech Stack)

- **Frontend:** React 19, TypeScript, Tailwind CSS v4, Lucide Icons, Canvas API, Web Speech API.
- **Backend:** Node.js, Express, tsx.
- **AI Integration:** Google Gemini 3.8 Flash عبر الحزمة الرسمية `@google/genai` مع محرك محلي ذكي (Offline Fallback Engine) يعمل في جميع الظروف.

---

## 🔑 إعداد متغيرات البيئة (Environment Setup)

أنشئ ملف `.env` في المجلد الجذري:

```env
# مفتاح Google Gemini API لتشغيل ميزات الذكاء الاصطناعي الحية
GEMINI_API_KEY="YOUR_GEMINI_API_KEY"

# رابط التطبيق عند النشر (اختياري)
APP_URL="http://localhost:3000"
```

> **ملاحظة هامة:** إذا لم يتوفر مفتاح API، ستعمل المنصة بالكامل بسلاسة فائقة وبدون أي أخطاء بفضل "محرك الميكاترونكس المحلي الذكي" المزود بقواعد المعرفة الهندسية.

---

## 📦 التشغيل المحلي (Running Locally)

```bash
# تثبيت الاعتماديات
npm install

# تشغيل بيئة التطوير الكاملة (Frontend + Backend)
npm run dev

# بناء المشروع للإنتاج
npm run build

# تشغيل خادم الإنتاج
npm start
```

يعمل التطبيق على المنفذ: `http://localhost:3000`.
